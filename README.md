# Browser Game Prototype

정적 HTML/CSS/JavaScript로 만든 브라우저 게임 프로토타입입니다.

## Local play

`index.html`을 브라우저로 열거나, 로컬 웹 서버에서 실행하세요.

## Controls

- `A` / `D`: move
- `Space`: jump
- Left mouse click: sword attack
- `Tab`: inventory

## Deploy

GitHub Pages는 이 저장소의 기본 브랜치 루트에서 `index.html`을 제공하도록 설정합니다.

## Effect regression audit

로컬 웹 서버에서 `/?effectAudit=1`을 열면 장비·잔흔 단독 효과와 모든 2종 조합을 3회 자동 검사합니다. 일반 게임 주소에서는 감사 코드가 로드되지 않습니다.
